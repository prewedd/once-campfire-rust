# Frontend overrides

Files in `overrides/` shadow the reference app's assets of the same logical path (the path under
`app/javascript`, `app/assets/*` or a vendored gem's asset directory), so the Rust app can change its
frontend without editing the `reference/` submodule. `build.rs` puts that directory first on the load
path.

| File | Differs from the reference by |
|---|---|
| `models/file_uploader.js` | No `X-CSRF-Token` header: pages carry no CSRF token (forgery protection is by `Sec-Fetch-Site`) |
| `controllers/copy_to_clipboard_controller.js` | A `url` value: a path, copied as an absolute URL against the page, so the cached message markup that carries it doesn't depend on the request's host |
| `lib/autocomplete/base_autocomplete_handler.js` | Asks for JSON (`Accept: application/json`). The reference passes `{ as: "json" }`, a `@rails/request.js` option, to plain `fetch`, gets HTML and never shows the new-ping suggestions |
| `install-edge.svg` | New: a copy of `external/install-edge.svg` where `pwa/_install_instructions` looks for it. Rails can't find it, so Edge gets a 500 on profile and room pages |
| `controllers/composer_controller.js` | A `threadId` value: a thread's composer keeps its draft apart from the room's ([threads](../../plans/threads.md)) |
| `controllers/typing_notifications_controller.js` | A `threadId` value: typing in a thread subscribes with `thread_id`, so only that thread sees it ([threads](../../plans/threads.md)) |
| `threads.css` | New: the thread summary under a message and the thread view ([threads](../../plans/threads.md)) |
| `workspace.css` | New: PreWedd's workspace look ([redesign](../../plans/redesign.md)); sorts after every other stylesheet |
| `fonts/inter-*.woff2` | New: Inter 4 (Latin, Latin Extended, Cyrillic, Cyrillic Extended), from Google Fonts; SIL Open Font License 1.1 |
| `emoji.svg` | New: the composer's emoji button |
| `emoji/data.json`, `emoji/prompt.html` | New: the emoji picker's emoji and the `:` prompt's suggestions, generated by `script/generate_emoji.py` from emojibase-data 15.3.2 (MIT) |
| `lib/emoji/picker.js`, `lib/emoji/boosts.js`, `controllers/emoji_controller.js` | New: the emoji picker, adding a reaction, and the composer and reaction buttons that use them |
| `initializers/index.js` | Also imports `initializers/workspace` |
| `initializers/workspace.js` | New: reactions as counted pills you toggle; the current room marked in the sidebar |
